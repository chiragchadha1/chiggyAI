## The problem

Customers kept finding outdated photos and old menus scattered across the web, which created
real confusion about what the shop actually serves. The store needed one source of truth it
controlled.

## What I built

A Next.js site with React and Framer Motion, designed and built end to end using AI coding
tools. Homepage with hero, auto-scrolling photos, about section, and a catering call to
action. A full daily menu page with search. A catering page with packages and pricing.
Every order button routes to ChowNow, and the whole thing is mobile responsive on Vercel.
