## The origin

I started DEFYE in September 2017, in high school, designing logos and profile pictures. A
client wanted a promo video, so I taught myself After Effects, then Cinema 4D, then the full
Adobe suite, all before Figma existed. Web design came last, and by the end it was a full
creative shop run mostly solo, because the work was better when I owned it end to end.

<Diagram name="craft-timeline" />

## What it became

DEFYE earned around $25k across 50+ clients through college. After graduating I folded it
into chiggyAI Inc (incorporated 2026). chiggyAI is now the
home for my own products.

The direction now is AI agents built on the same [chiggyOS](/work/chiggyos) infrastructure I
use for myself. Sub-agents that triage inbound mail, draft responses (never auto-send), and
handle recurring operations, with a deterministic layer before any model call so the
behavior is predictable and auditable.

The throughline from graphic design to motion to web to AI is the same instinct every time.
Go deeper until I own the whole stack.
